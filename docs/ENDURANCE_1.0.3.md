# 1.0.3 真实游戏长测清单

这是待执行清单，不是已通过证明。安全停止后保留整个Session目录和logs；诊断摘要默认排除私人信息。

## 操作记录

1. 每代可用游戏分别测试，记录游戏品牌/赛季/UDP格式、发送频率、端口、硬件和时长。
2. 连续驾驶、暂停/恢复、回车库查看分析、出站换胎；尝试浏览旧圈/缩放区间时继续跑圈。
3. Flashback跨圈线以及车库边界，重跑后核对最终有效历史和三个赛段。
4. 切换练习/排位/比赛会话，检查目录UID、首个可靠上下文、未归属输入和同UID后续变化；没有实际冲刺数据时不勾选冲刺识别。
5. 停止后复制整个Session，在新路径继续分析。旧缓存不匹配时确认独立重建，旧库不应覆盖。
6. 旧Raw压缩中取消；大Session分析中取消、再继续；窗口X和安全按钮都应等安全收尾。

## 核验

- 每个Raw严格遍历CRC/Header，与索引及已有Foundation核对；统计所有档案总量，不能只看最后一个目录。
- Flashback前的Raw证据保留，但派生结果只采用有效分支。
- 混合身份/缺失帧明确列为质量问题，无法归属差额不得强行分配。
- 只包数变化不改变圈/驾驶段/缩放；新完成圈、撤回和真实内容修订应更新。
- 诊断状态区分显示问题、分析积压、写入失败、资源压力；没有数据到达不能显示为持续取得游戏数据。
- 记录首末/峰值内存、进程CPU时间、磁盘占用、队列峰值、分析积压及故障日志，不能从合成测试推断游戏FPS。
- 正常停止后SQLite完整性、最后完整块及Replay可用。强杀/断电仅在可丢弃测试档案中测试，未提交尾部可能损失。

验收时填写实际操作、期望、结果、数据目录和异常时刻。不要把缺少测试条件的项目标成通过。
