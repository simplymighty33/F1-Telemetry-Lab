# F1 Telemetry Lab 1.0.3

2026-10-02。本地正式命名与打包，整合此前 a/b/c 功能及完整审查的可靠性、性能和使用体验修整；不自动发布 GitHub。

## 本次修整

- 分析帧强制同玩家、协议和游戏帧号；不一致记录为质量问题，不生成混合有效样本。低频状态按玩家/协议隔离，不回填未来状态。
- 显示异常不停止 Raw，窗口提示需核验；磁盘错误/队列溢出仍明确停止。
- 保留游戏 Session 分档与可查找目录名，晚到包归回原档案。状态读取不等待 Raw 写盘锁；后台收尾异常公开提示。
- 重复历史不再逐圈UPSERT，按受影响会话/圈更新指标和驾驶段，增加内容修订号。
- 单圈对比移到一个有界后台任务，缓存最多4个结果；过期结果不覆盖新选择。仅包数或剩余比赛时间改变不重置图表；相同圈保留缩放和可匹配的区间选择。
- 新增算法兼容签名，默认结果在独立 `analysis_v1.0.3/`。旧库只读保留，不混写不同算法结果。
- 搬迁/不兼容旧缓存支持确认后独立重建，建立新的分析和基础缓存，不要求删除旧库。
- 逐圈表按稳定圈ID更新，浏览旧圈时保留滚动；打开无效数据库前验证实际视图查询，失败保留原选择。
- 最近数据库发现覆盖版本化目录；配置拒绝NaN/Infinity，接收/队列等待上限5秒、状态报告间隔上限3600秒。
- 长任务有阶段/数量与安全取消；压缩取消不发布副本，分析保留已提交进度。离线事件流式导出，错误总数准确、明细最多200项。
- 版本和打包目录统一为1.0.3；当前指南与历史说明分离，历史合并指南保存到 `docs/history/`。

## 升级与边界

完整解压新包，不只替换EXE。原录制和a/b/c安装目录不改动。Raw v1/v2和CRC/FULL/fsync/Flashback语义保留，没有删除AI数据、降采样或增加第三方运行依赖。

首次建立新算法结果可能需要处理现有基础缓存；搬迁旧缓存的独立重建需重新读取Raw。已处理数据的后续打开继续复用。路径/UUID和CRC并非防篡改认证；怀疑同大小/同时间戳文件被替换时请独立重建或完整来源校验。

取消是协作式安全取消，不强制打断系统I/O、刷盘或一个正在执行的单圈计算。自动化、故障注入、合成负载和只读历史库测量不等于真实游戏长测，亦不保证断电零损失。

冲刺/正赛可靠识别按原约定继续保留待办，需要标注的冲刺周末数据。地图和自动教练建议未加入。
