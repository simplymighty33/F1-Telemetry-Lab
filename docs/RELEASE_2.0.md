# RaceTrace Lab 2.0

2026-10-11。程序版本 2.0.0；窗口显示 2.0；Windows 包短名 racetrace2.0。
地图测试程序仍独立，不集成、不覆盖。

[Windows 下载包](https://github.com/simplymighty33/F1-Telemetry-Lab/releases/download/v2.0.0/racetrace2.0.zip) · [English notes](RELEASE_2.0.en.md) · [中文使用说明](qt-command-center-guide.md)

## 主要变更

1. 正式采用已确认的 Qt 三页界面、RaceTrace Lab 名称及图标、集中字体角色与高 DPI 绘制。
2. 修正 F1 25 更新后的 2026 格式运动包、车辆遥测包：24 车数组，54/59 字节车记录，G 值恢复实际单位；完整解码与快速玩家解码共用转换。
3. 修正计时赛回车库／重新开始圈后，同一圈号中多个尝试误按覆盖长度选取的问题。跳过车库传送样本，按官方历史圈速匹配最新完整尝试；末尾未完成尝试不覆盖已完成圈。
4. 数据质量检查识别 flying-lap 状态；真实缺口、时序回退、缺少通道继续保留，不用平滑或更改测试期望掩盖。
5. 采集页显示后台解码拒绝计数与保留 Raw／独立重建建议，和 Raw 写入错误分开。Header 解析成功不等于所有包体均解析成功。
6. 新缓存独立存储：基础缓存 v3、分析目录 analysis_v2.0、引擎契约 10、质量契约 2。旧 Raw 与分析数据库保留。
7. 统一品牌/版本、Windows EXE 属性、默认 Qt GUI 入口和文档；保留原 CLI 与显式 Tk 回退。精简快照重复读取，共用字段转换与路径常量；不删兼容入口、不重写采集线程。

## 已有问题的恢复方法

不要覆盖安装，不要删除原 Raw。解压到新的可写目录后启动，打开右上工具菜单：

- 选择旧 Session 目录进行“构建 / 续建”，生成新的基础缓存与 2.0 分析。
- 若需要完全排除旧缓存影响，停止该 Session 的录制后选择“独立重建”，会生成新目录。
- 仅“打开分析数据库”不会重新解析 Raw，因此打开旧错误结果仍会显示旧状态。
- 未知包版本、损坏 Raw、真正缺失数据不能通过此修复凭空补齐。

当前支持 packetFormat 2023/2024/2025/2026 的 packetVersion 1。
车辆规则与 UDP 格式不是一回事，不能按“2025 赛车”强制套用 2025 布局。
本次真实样本为 F1 25 / 2026 格式 / 2025 规则赛车；不宣称已完成 2026 规则赛车长测。

## 数据与功能边界

Raw 存储结构、压缩格式、来源身份、原始字段、单位、Flashback、事务恢复和排空流程不变。
新圈段选择只在计时赛应用；非计时赛的既有距离回退处理不变。
末帧时钟与官方时间允许最多 250ms 的采样差，轨迹需覆盖至少 90% 圈长、末帧处于终点前 25m 以内；
这是保守匹配阈值，不表示时间/位置测量精度。匹配失败或真实采样缺口不会呈现为可靠分析。
地图、ERS 能量部署曲线及 AI 调教建议未在主程序中新增。

## 协议依据

字段修正核对 EA 官方 [2026 Season Pack UDP 结构说明](https://forums.ea.com/t5/s/tghpe58374/attachments/tghpe58374/f1-games-game-info-hub-en/61/8/2026%20Season%20Pack%20Telemetry%20Output%20Structures%20%281%29.txt)：
Motion 1325 字节、三个量化 G 分量为 int16 且除以 1000；Car Telemetry 1448 字节、发动机温度为 uint8。
Telemetry 2 中另有车辆规则标志，因此保留游戏／协议／车辆规则的区分。

## 验收与限制

实测档案 230,335 包完整 Replay；33,114 玩家帧；3 个完成圈均恢复可分析。
完整 Replay 与增量缓存的主要数据表逐行一致。真实数据只在隔离副本上构建。
255 项 unittest 回归通过。打包 EXE 对 2023 / 2026 合成协议的两次本机 UDP 测试均为发送 / 接收 / 写入 / 解码 400 包，Raw 字节及 Header 一致，安全关闭通过。
界面验收覆盖 1366×768 / 1920×1080 与 DPR 1 / 1.25 / 1.5 / 1.75 / 2 的逻辑渲染矩阵，并补测小窗口；模拟矩阵不等于真实多显示器跨屏验收。
Windows 包 347 文件，ZIP CRC 和逐文件 SHA-256 核验通过，最长归档条目 119 字符。不附带游戏地图资源、系统字体、测试 Raw 或用户日志。
公开源码排除内部代理配置、机器安装记录及本地配置，保留程序代码、图标、测试、构建脚本与第三方许可正文。
新 EXE 尚需游戏电脑长测、F1 24/25 更多比赛模式、干净 Windows 及真实混合 DPI 验证。
模拟缩放或本机 UDP 回环不等同于上述验收。
