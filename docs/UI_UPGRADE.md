# UI 升级预览（基于 1.0.3）

本次是本地界面升级预览，不是 GitHub 的新正式版本。程序版本与分析缓存契约仍为 1.0.3；不要用预览包覆盖正在运行的正式程序。

## 已实现的第一阶段

- 主界面缩小标题和固定信息区，将端口编辑放入「连接设置」、接收时间与完整路径放入「录制详情」。错误提示、安全停止按钮不依赖展开详情。
- 单圈分析将导入、恢复、压缩和长测审计放入可展开「数据工具」；来源模式常驻，完整路径按需查看。取消按钮只在后台任务执行时出现。
- 侧栏按窗口空间和字体度量自动收起，可手动展开且保留用户选择。单圈状态说明与质量表一起展开，减少顶部高度。
- 图例常驻；速度/油门采用基准实线、对比长虚线，制动采用短虚线/点划线。悬停和键盘左右键可读时间差、速度及输入；Ctrl+0恢复整圈。数据缺口不被跨越连线。
- 复盘统一深色控件，突出有效圈、最快圈、中位和极差，条件解释可展开。刷新后台读取原来源的已提交快照，不重放Raw；页签、圈选择和滚动位置尽量保留。
- 切换分析档案不会改变已打开复盘的来源；关闭正在刷新的复盘不会被结果重新打开。退出先停止接受新任务，再沿用原有安全关闭流程。
- 长测审计先展示可读结果，技术JSON放入第二个页签；缺失字段显示未知/待核验，不伪装通过。导出仍沿用去身份化结果。
- 中文与英文使用说明同步更新。

## 2026-10-03 单圈图表补充

- 时间差、速度、油门、刹车改为四块上下排列且距离对齐的图表；油门/刹车各两条曲线，不再四线混画。颜色与线型保留。
- 鼠标旁的轻量Canvas提示显示最近采样距离、当前图表的基准/对比数值；输入显示至0.1%，速度至0.1 km/h。键盘左右键和底部读数保留。
- 缺口/不可靠采样只提示警告；移出绘图区、切换圈/区间、滚动或调整窗口清除旧提示。浮框在可见图表内避让边缘。
- 字体度量决定图表最小高度。小窗口/高缩放必要时提供图表纵向滚动，不压缩至标签重叠；两端距离刻度不再被窗口边缘裁切。
- 新增实际Tk事件验收：分图与距离对齐、精确值、缺口、键盘与状态清理、200%缩放、已加载分析窗口。未改变采集、分析算法或数据格式；仍是本地预览，非正式发布。

## 保持不变

Tkinter/ttk/Canvas 与标准库运行时；UDP、Raw v1/v2、CRC、来源偏移、Flashback和恢复进度契约不变。未增加图片资源、动画、框架或运行时依赖。没有向主界面加回包数、包速率或队列仪表。

## 检查与限制

自动化检查使用临时数据库/Raw及回环UDP，不修改用户录制。布局覆盖1366×768、1920×1080以及96/120/144/192 DPI，并检查空白启动和已加载单圈。新增测试覆盖设置/详情折叠、侧栏、键盘图表、复盘刷新与历史来源隔离。

Tk控件的实际几何测量不等同于截图目视验收、读屏兼容认证或真实游戏耐久测试。请在游戏电脑检查中文字体、下拉列表、不同缩放、长错误文本、图表悬停及窗口关闭。

代码审查分标准约束和用户需求两轮顺序进行，比较本次修改前的明确源码副本与当前文件；没有假称Git历史或独立代理审查。已修正标题早期换行、Tk窗格名称类型判断、已加载数据时的图表挤压以及测试窗口回调清理问题。
