# F1 Telemetry Lab 1.0

本次发布仅更名及调整单圈分析布局，内部语义版本 `1.0.0`。不是新的协议或驾驶分析算法版本。Raw 格式、基础缓存 schema、分析 schema、增量引擎版本和结果目录均不变，继续读取旧 Raw 及数据库。不主动迁移或重建旧档案。

## 界面修正

- 初始窗口从 1180×820 改为最大 1440×940，并按屏幕尺寸减去边缘预留；最低尺寸也不会超过对应屏幕预留范围。
- 标题与按钮不再争抢同一行。工具栏根据按钮实际所需宽度自动使用一至三列。
- 主分析窗口改为弹性网格，优先为顶部控件和底部状态保留空间，剩余区域交给图表。图表提示也有独立保留位置。
- 未载入圈数据时隐藏空质量表及重复提示。矮窗口默认收起质量表；用户可用独立按钮展开，手动展开/收起在窗口内保留。
- 会话、圈选择、驾驶段均随窗口拉伸；质量文字和状态文字换行；指标表新增上下与左右滚动。小屏幕高缩放下只能保证控件可访问，细看曲线仍建议最大化。

## 产品命名

窗口标题与显示版本统一使用 `collector.APP_NAME`、`DISPLAY_VERSION`；Windows 文件/产品版本为 1.0.0。EXE 为 `F1TelemetryLab.exe`，分发目录 `F1TelemetryLab-1.0`，指南为 `F1TelemetryLab-1.0-使用说明.txt`。源码目录与旧打包配置文件名不强制改动，避免打断已有脚本；旧命令行入口保留。

## 升级

保留旧文件夹、Raw 和旧分析。复制整个新分发目录，不只复制 EXE。新程序默认使用其旁边的 config/data/logs，旧设置可在关闭两版后复制 settings.json。打开旧 Session 直接选择其位置，可复用 `analysis_v0.10.0` 缓存，不必复制大型录制。两个程序不要同时占用同一 UDP 端口。

## 验收范围

布局回归覆盖空数据首次打开、已载入数据、长状态文字、1366×768/1920×1080、96/144/192 DPI 模拟，以及质量折叠按钮。发布程序另验收品牌属性、无数据库启动、旧分析数据库、UDP 协议接收、后台分析、端口持久化和手动关窗保护。实际多显示器、系统任务栏特殊布局及游戏电脑仍建议复测。

完整回归 102 项通过。正式 EXE 无数据库分析窗口在本机首次启动为 1380×860；主窗口及分析窗口标题均为新名称，Windows 产品/文件版本为 1.0.0。472 包构造多协议验收中 Raw、基础缓存、增量分析数量相同，无解析错误；端口重载、轮胎显示和各窗口安全关闭弹窗通过。机器可读报告为 `outputs/release_1.0_final/release_verification.json`。
