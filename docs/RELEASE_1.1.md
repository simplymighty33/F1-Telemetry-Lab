# F1 Telemetry Lab 1.1 — 距离区间分析

## 范围

新增时间区间和操作对照，不修改 UDP 接收、Raw 压缩、Header 解码、基础缓存和 Flashback 分支归并。无新增运行依赖。内部版本 1.1.0，完整离线派生引擎版本 6；分析 schema 3、增量检查点版本 1 和默认增量目录不变。

## 分析规则

- 两圈按共同距离位置比较。对比减基准：正值损失，负值获益。
- 50米窗口平滑仅辅助区间边界选择；区间金额取未平滑的累计差端点之差。
- 小于30米或20毫秒的碎片合并，剩余小变化仍列出，不删金额。有效连续区间完整分区，无重叠、无遗漏。
- 官方整圈差 = 已观察区间合计 + 未归属差额。未归属不作具体弯道归因，不将终点差额摊入数据缺口。
- 操作对照使用两圈相同区间：入口/最低/出口速度、制动跨越5%、最低速后油门跨越98%、最低前进挡。没有实际跨越时显示未观察到；最低速度不命名为几何弯心。
- 门槛是可调研的初始工程参数，不是官方标准或精度承诺。未覆盖的油门建立、区间外制动不会外推。

## 质量保护及旧库

新重采样拒绝超过50米或1500毫秒的源采样间隙、关键时间/速度/油门/制动字段异常和明显非单调计时。局部距离不超过5米且时间回跳不超过50毫秒时，只在派生内存视图中修正为前值。真实长测包含这种小抖动；不改 Raw 或原始表。

旧库打开时从源采样重新核验所选两圈，不信任已经插值成连续曲线的数据。缺口断开绘制并停止该区间操作分析；旧原始表不够时明确拒绝生成可靠区间。旧整圈指标仅保留显示，不声称全部已按新门槛重算。读取圈速、样本和事件使用同一 SQLite 快照，避免后台更新时混合两条时间线。

轮胎配方不同/磨损差至少5个百分点时提示。其他比赛条件尚不自动完整校验，不能把操作差异直接解释为因果或给出驾驶评分。地图与练习段趋势汇总留到后续。

## 验收

新增测试覆盖相同圈零差、恒速解析解、区间金额守恒、碎片合并、数据缺口/缺字段/时序异常、旧库只读、共同边界操作、离散挡位、无虚构油门恢复、窗口联动和小屏高缩放。完整回归及真实 Raw 全量/增量对照结果另存于本地验收输出；不将合成包测试等同于 F1 24/25 实际长测。

本次完整回归125项通过。真实 F1 23 录制624,609包、12次Flashback、11个完成圈，经直接 Raw Replay、基础缓存及每10,000包重开增量检查点三条路径生成的12张结果表逐行哈希一致。Raw SHA-256前后一致。55组双圈比较均通过连续有效区间完整分区与金额守恒，比较生成中位0.204秒、最慢0.429秒（本机单次样本，不是性能承诺；首次整场重建约17秒另计）。未归属差额保留，不声称采样覆盖到准确终点。

正式EXE窗口/产品版本1.1.0验收通过：472个合成多协议包在Raw、基础、增量分析层计数一致且无解码错误，保存的UDP端口重新加载成功，主窗口和空/旧库分析窗口手动关闭等待弹窗通过。此合成录制没有完整有效遥测圈，时间区间算法的验收来自上述真实录制及专门测试，不由这472包证明。无新增运行依赖；ZIP不包含测试录制、配置或日志。
