# RaceTrace Lab 2.0 使用说明

打开 `RaceTraceLab.exe`。必须保留同目录 `_internal` 与许可文件，不需要安装 Python。
本包采用新版 Qt 界面与 2.0 解析核心。请解压到新目录，不要覆盖旧安装。
名称和图标已统一为 RaceTrace Lab；录制目录、配置、协议和历史数据身份不变。
首次启动创建本包目录下 config / data / logs。历史录制不会自动复制、删除或重建。

## 实时采集

游戏中启用 UDP，F1 23 / 24 / 25 协议自动识别。默认端口 20777。
右上“来源与工具 → 连接与存储设置”修改端口和完整输出目录；确认后先安全停止旧监听再重启。
采集页显示游戏、赛道、环节及最新在上的圈记录、三段计时和轮胎磨损。
Raw 状态与基础 / 分析状态分开，分析错误不代表 Raw 接收失败。环节未知时不猜测冲刺 / 正赛。
切换页面不会停止采集。可通过工具菜单单独停止采集，仍保留分析窗口。

## 单圈比较

“分析当前录制”自动跟随当前已提交分析，无须每圈手动导入 Raw。
“打开分析数据库”是历史只读模式，不随游戏改变；“分析当前录制”可重新连接实时来源。
选择会话、驾驶段、基准和对比圈；列表上下键选择对比圈。
圈名包含赛道、环节、圈号、轮胎磨损与圈速，例如“澳大利亚 · 练习赛2 · 第11圈｜软胎（磨损8.4%）｜1:19.335”。图线分开显示时间差 / 速度 / 油门 / 刹车，每图右上方标示线条身份。
蓝实线=基准，琥珀虚线=对比，时间差=对比−基准。负官方差才表示对比更快。
图表悬停显示原采样数值；图表获得焦点时左右键逐原样本步进；Esc 清游标，Ctrl+0 恢复整圈。
滚动查看下方图表，鼠标横向拖动 / 滚轮可调整距离视口。四图横向联动。
较窄窗口自动把右侧详情折叠；使用“区间 / 质量面板”与“返回图表”切换，不裁掉大圈速数字。
右侧可切换时间区间、整圈指标、数据质量；选择区间会聚焦，选择质量行可看完整详情。
官方圈差、可归属与未归属差额独立显示，缺口处不连线 / 不显示可靠值。
地图和 ERS 曲线尚未接入，可以折叠能力提示；不影响四图分析。

## 练习与离线工具

单圈页选择范围后生成练习报告：圈次 / 赛段统计、胎组与燃油 / 胎温 / ERS 条件证据、重复损失区间。
ERS 条件中位数不是储能曲线或能耗分析。未知通道为 —，不是零。
双击有支持、有损失圈的重复区间可回到单圈页聚焦；区间不是弯道编号或驾驶原因。
来源 / 会话 / 驾驶段切换会使旧报告失效，同来源刷新保留选择和滚动位置。

右上工具菜单提供 Session 构建 / 续建、独立重建、压缩 Raw 和只读审计。
已有分析不匹配时可另建；不完整尾部仅在确认后恢复完整已验证前缀，CRC 错误不忽略。
F1 25 旧版出现“缺少运动／样本不足”时，请选择原 Session 的 Raw 独立重建；只打开旧分析数据库不会修复旧结果。
新缓存为 foundation-v3 / analysis_v2.0，旧文件不会被覆盖。计时赛重复尝试按官方完成圈计时匹配。
后台解码失败提示不等于 Raw 丢失；请保留原文件供升级重解析。
压缩保存副本并验证，原 Raw 不替换；活动录制不能压缩 / 独立重建 / 完整离线审计。
底栏显示后台进度并允许取消。取消保留已有安全进度。结果窗口中可复制产物路径与 JSON。

## 退出与验收限制

点“安全停止并关闭”或系统关闭按钮，都会显示等待窗口，排空 Raw 和所有后台任务后一起关闭。
请勿通过任务管理器强杀进程；断电 / 强杀不是 GUI 安全退出能够保证的情形。
本批已做保存 Raw 的完整重放；新版真实游戏长测、干净 Windows 与混合 DPI 显示器测试尚未执行，请保留旧安装和原始档案。
